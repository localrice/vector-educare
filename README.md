# Vector Educare

This is the deployed static site for **Vector Educare**, hosted on GitHub Pages and connected to the custom domain: [vectoreducare.in](https://vectoreducare.in).

## About

- **Static Site:** This branch contains the static version of the website.
- **Deployment:** automatically deployed via GitHub Pages.
- **Custom Domain:** Configured to use [vectoreducare.in](https://vectoreducare.in) for easy access.

## Technologies Used

- **HTML5, CSS3, JavaScript:** Just the usual stuff I used to build the site.
- **Other Libraries:**   
    - [Font Awesome](https://fontawesome.com/) for icons  
    - [FormSubmit](https://formsubmit.co/) for static form handling (lets you receive form submissions directly to your email without needing a backend)

## Other Versions

- **Dynamic Version:**  
    The `main` branch contains a dynamic version of the site, featuring an admin page for content management and updates.
